# cove

**Своя экосистема на Hyprland:** шелл, редактор, терминал и браузер в одном стиле.
Всё настраивается мышкой, без правки конфигов.

## Что внутри

**Шелл на Quickshell**
- **Панель** — 8 стилей (Чёлка, Капли, Капсулы, Стекло, Плитки…) и ручная настройка каждого модуля.
- **Динамический остров** — часы, плеер со спектром, уведомления, громкость, превью скриншота;
  при наведении раскрывается с кнопками действий.
- **Лаунчер** — приложения, калькулятор `=`, файлы `/`, команды `>`, поиск по сайтам `!yt котики`,
  окна `@`, буфер обмена `:`. Нечёткий поиск, избранное, 5 стилей.
- **Центр управления** — Wi-Fi, Bluetooth, звук, ночной свет, «Не беспокоить», игровой режим.
- **Виджеты рабочего стола** — 16 штук (часы, погода, плеер, спектр, задачи, календарь…)
  с редактором прямо на рабочем столе.
- **Обои** — смена по времени суток, свои на каждый воркспейс, слайд-шоу. Цвета всей системы
  берутся из обоев (или из обложки играющего трека).
- **Скриншоты и запись экрана** с редактором, пипетка, буфер обмена, заметки, фокус-таймер,
  экран блокировки, обзор воркспейсов.
- **Настройки** — 17 разделов: хоткеи с записью сочетаний, правила окон, профили стилей,
  ввод, автозапуск, бэкап дотфайлов в git.
- Русский и английский интерфейс.

**Cove Code** — терминальная IDE на движке Neovim, но работает как обычный редактор:
мышь, вкладки, дерево файлов, меню, палитра команд, LSP, Ctrl+C/Ctrl+V. Запуск — `cove`.

**Firefox в стиле Cove** — цвета меняются вместе с темой на лету, 5 видов интерфейса
(плавающий, одна строка, остров, вертикальные вкладки, классический), своя стартовая страница.

**Терминал** — kitty + fish + starship, цвета из обоев, fastfetch со знаком Cove.

## Установка

Нужен **Arch Linux** (или производный). Все пакеты — из официальных репозиториев, AUR не нужен.

```sh
git clone https://github.com/cvsqwe/cove ~/cove
cd ~/cove
./install.sh
```

Установщик спросит про необязательное: пак обоев (~700 МБ), курсоры, настройку Firefox,
экран входа, fish по умолчанию. Затем войдите в сеанс **Hyprland**.

Отдельные шаги можно запустить потом: `./install.sh firefox`, `./install.sh wallpapers`,
`./install.sh cursors`, `./install.sh greeter`. Все шаги: `./install.sh --help`.

### Как это устроено

Конфиги ставятся **симлинками** на клон репозитория (список — `links.txt`).
Всё, что лежало на их месте, переезжает в `~/.local/state/cove/backup-<дата>/`.

- **Обновить:** `cd ~/cove && git pull`
- **Удалить:** `./uninstall.sh` — уберёт симлинки и вернёт ваши старые файлы.
- **Ваши настройки** хранятся в `config/quickshell/settings.json` и в git не попадают.
- **Мониторы** (частота, расположение) — в `~/.config/hypr/monitors.lua`, он тоже локальный.

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| `Super + Пробел` | лаунчер |
| `Super + ,` | настройки |
| `Super + /` | шпаргалка всех хоткеев |
| `Super + Q` | терминал |
| `Super + Esc` | меню питания |

Все сочетания меняются в **Настройки → Хоткеи**.
